# Checklist iPhone / radio

- [ ] Le site est servi en HTTPS.
- [ ] Safari demande le microphone uniquement après **Démarrer**.
- [ ] Refuser le microphone affiche une erreur compréhensible et permet de réessayer.
- [ ] Plusieurs cycles Démarrer/Stop fonctionnent.
- [ ] Une émission CW du FT-710 est détectée entre 400 et 1000 Hz.
- [ ] Une émission CW provenant du SDR est détectée.
- [ ] AUTO suit la porteuse dominante.
- [ ] LOCK conserve la porteuse suivie lorsqu'une autre station apparaît.
- [ ] La fréquence BF, les WPM, la confiance et les points/tirets évoluent à l'écran.
- [ ] Le texte décodé reste lisible sur iPhone en portrait.
- [ ] Effacer et Copier fonctionnent.
- [ ] Passage arrière-plan puis retour : aucun faux caractère n'est ajouté.
- [ ] Safari > Partager > Ajouter à l'écran d'accueil installe la PWA.
- [ ] La PWA se relance depuis l'écran d'accueil.

La validation radio réelle doit être faite avec plusieurs niveaux de haut-parleur, vitesses CW et niveaux de bruit avant de considérer la V1 comme validée.
